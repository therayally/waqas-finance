Setup (once, on your own computer)

Needs Node 18+ and Claude Code (claude) already installed and signed in on this machine.

  1. Download the relay: curl -fsSLO https://waqas-finance.vercel.app/pf-relay.mjs (or save it from the Files menu of your browser on this page's address)
  2. Get the relay key: ask whoever set this app up for the AGENT_RELAY_KEY value.
  3. Run it: PF_API_KEY=<the relay key> node pf-relay.mjs — leave that running while you want the assistant to answer.
